# Youssef Najari — Portfolio

Professional portfolio of **Youssef Najari**, full-stack engineer (web & mobile), based in Fez, Morocco.

**Live site (after GitHub Pages):** https://youssefnj.github.io

## What’s inside

- English-language site
- Profile, skills, experience, projects, education, contact
- Downloadable CV
- Ready for GitHub Pages

## Local development

```bash
npm install
npm run dev
```

## Publish on GitHub Pages

1. Create a **public** repository named `youssefnj.github.io` on your GitHub account (`youssefnj`).
2. Push this project to that repository (`main` branch).
3. In the repo: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
4. After the workflow succeeds, the site is at `https://youssefnj.github.io`.

```bash
git remote add origin https://github.com/youssefnj/youssefnj.github.io.git
git add .
git commit -m "Add professional portfolio"
git push -u origin main
```
